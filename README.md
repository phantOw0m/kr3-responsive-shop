## Краткое описание проекта
Проект представляет собой адаптивную версию сайта доставки еды Food & Joy (созданного в рамках КР №1). ## Адаптивные решения
В проекте использован подход **Mobile First**. Все базовые стили написаны для мобильных устройств, а для планшетов и ПК используются медиазапросы (`min-width`).
- Создан и подключен отдельный файл `css/responsive.css`.
- **Навигация:** На экранах до 767px меню скрывается и появляется кнопка-бургер (реализована через JS). На ПК меню возвращается в горизонтальную строку.
- **Сетка карточек:** Сетка каталога перестроена с помощью CSS Grid. На мобильном — 1 колонка, на планшете — 2, на ПК — 2 крупные колонки.
- **Формы:** На мобильных устройствах поля ввода (`input`, `textarea`) растягиваются на 100% ширины, чтобы не выходить за края экрана.
- **Таблицы:** Таблица характеристик на странице товара адаптирована. На ПК она выглядит как классическая таблица, а на мобильном превращается в удобные карточки.
- **Responsive Images:** Для изображений используется базовое правило `max-width: 100%; height: auto;`. Для карточек товаров применены атрибуты `srcset` и `sizes` для корректной загрузки на разных экранах.

## Доступность (A11y)
- Добавлена «Скип-ссылка» (Skip-link) для быстрого перехода к основному контенту с клавиатуры.
- Настроен видимый фокус (`:focus-visible`) для всех интерактивных элементов.
- Проверено наличие логичных заголовков и атрибутов `alt` у изображений.
- Кнопка мобильного меню имеет `aria-label`.

## Lighthouse
Проверка доступности (Accessibility) выполнена в браузере Chrome для страниц `index.html`, `catalog.html`, `order.html`. 
Оценка доступности составляет **95/100**. Скриншот отчета сохранен по пути: `lighthouse/accessibility-report.png`.

## Проверенные ширины
Верстка проверена и корректно отображается на следующих ширинах экрана:
- 360px (Mobile)
- 430px (Mobile L)
- 768px (Tablet)
- 1024px (Desktop)
- 1440px (Desktop L)
